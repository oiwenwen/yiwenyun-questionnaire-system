# 部署指南

面向把本项目部署到云服务器（以腾讯云轻量应用服务器 + 1Panel 为例）的场景。
使用 phpstudy / XAMPP 等集成环境时，只需要其中「建站」和「导入数据库」两部分。

---

## 1. 部署前先决定两件事

### ① 服务器地域与备案

| 地域 | 能否绑定域名 | 说明 |
|---|---|---|
| **中国内地**（上海 / 广州 / 北京等） | 需先完成 **ICP 备案** | 未备案时只能用 `http://IP:端口` 访问；分享出去的问卷链接会带端口号 |
| **境外**（香港 / 新加坡等） | 免备案 | 可直接绑定域名并签发 HTTPS 证书，代价是访问延迟略高 |

ICP 备案需要域名实名认证、提交网站信息并等待审核，通常需要 1–3 周。
只是内部使用或临时演示的话，内地地域直接用 IP + 端口最省事。

### ② 服务器配置

本项目自身开销很小，主要资源消耗在面板、Web 服务器和 MySQL 上：

- **最低**：2 核 2G（可用，但面板操作和 MySQL 同时运行时偏紧）
- **推荐**：2 核 4G

## 2. 安装运行环境

1. 创建轻量应用服务器，镜像可直接选 **1Panel 应用镜像**（开机即是面板），
   或选择 Ubuntu 22.04 / Debian 12 后自行安装 1Panel。
2. 在云控制台的「防火墙」中放行所需端口（80、443，以及面板端口）。
3. 登录面板后**第一件事是修改默认密码**。
4. 在「应用商店」中安装：
   - **OpenResty**（或 Nginx）
   - **MySQL 5.7 或 8.0**
     > 只有打算直接拷贝 MyISAM 数据文件时才必须 5.7；**用 SQL 导入的话 8.0 也可以**。
   - **PHP 运行环境**（7.4 或 8.0）
5. 在「数据库」中新建数据库 `yiwenyun`，字符集选 `utf8mb4`，记下库名、用户名、密码。

## 3. 上传代码

### 方式一：Git（推荐）

```bash
cd /opt/1panel/www/sites          # 具体路径以面板的网站目录为准
git clone https://github.com/<你的账号>/<仓库名>.git yiwenyun
```

私有仓库通过 HTTPS 拉取需要 Personal Access Token（GitHub 已不支持账号密码），或改用部署密钥。

### 方式二：上传压缩包

本地打包时**排除** `config.php`、`.git/` 以及任何本地运行环境目录，上传后在面板「文件」中解压到网站目录。

## 4. 创建站点

在面板「网站」中新建网站：

| 配置项 | 取值 |
|---|---|
| 域名 | 有域名填域名；没有则填公网 IP，或用默认站点 |
| 根目录 | 指向含 `index.html` 与 `api/` 的那一层 |
| 运行环境 | 选择已安装的 PHP |
| 端口 | 80（或自定义） |

本项目全部使用真实文件路径，**不需要伪静态 / rewrite 规则**。

## 5. 导入数据库

**从已有环境导出：**

```bash
mysqldump -u root -p --default-character-set=utf8mb4 --databases yiwenyun --result-file=yiwenyun.sql
```

**在服务器上导入（二选一）：**

```bash
# 命令行
mysql -u <库用户> -p --default-character-set=utf8mb4 yiwenyun < yiwenyun.sql
```

或使用面板的「数据库 → 导入」功能上传 SQL 文件。

**全新开始**：直接导入 `_restore/schema.sql` 建表，再用注册 + 提权的方式创建管理员即可。

## 6. 配置并验证

编辑服务器上的 `config.php`：

```php
return [
    'host'     => '127.0.0.1',   // MySQL 与站点不在同一容器时，填写面板给出的连接地址
    'port'     => 3306,
    'dbname'   => 'yiwenyun',
    'username' => '数据库用户名',
    'password' => '数据库口令',
    'allow_register' => false,   // ★ 公网部署务必关闭自助注册
];
```

**推荐：直接用仓库附带的验收脚本，一次跑完全部检查**

```powershell
# 从你的 Windows 机器执行，目标指向线上地址
powershell -ExecutionPolicy Bypass -File tests\acceptance_test.ps1 -BaseUrl http://你的域名
```

脚本会自行注册测试账号、建卷、发布、匿名填写提交、查看结果、导出 CSV、删除问卷，
最后清理测试数据，输出 PASS/FAIL 汇总。

手工检查清单（与脚本覆盖的内容一致）：

- [ ] 打开 `http://域名或IP/index.html`，出现登录界面
- [ ] 能注册 / 登录
- [ ] 能新建问卷、添加三种题型并保存
- [ ] 能发布问卷并取到分享链接
- [ ] 匿名打开 `fill.html?id=N`，填写并提交成功
- [ ] 后台「查看结果」能看到该提交
- [ ] 导出 CSV，Excel 打开中文不乱码

## 7. HTTPS 与收尾

- 站点设置 → HTTPS → 申请 Let's Encrypt 免费证书（需域名已解析到本机；内地服务器还需完成备案）
- 开启「强制 HTTPS」
- 配置**自动快照**与每日 `mysqldump` 导出（见 `OPERATIONS.md`）
- 确认服务器上不存在任何调试用脚本

## 8. 常见问题

| 现象 | 原因 |
|---|---|
| 首页 404 / 空白 | 站点根目录指错层级（要指向含 `index.html` 的那一层） |
| 数据库连接失败 | 填了 `localhost`，但 MySQL 运行在容器中，需使用面板给出的连接地址 |
| 提交答卷报 SQL 错误 | 数据库时间列名不是 `submit_time`，详见 `OPERATIONS.md` |
| 中文乱码 | 库或表字符集不是 `utf8mb4`，或导入时未指定 `--default-character-set=utf8mb4` |
| 80 端口无法访问 | 内地服务器未备案，或云防火墙未放行端口 |
| 面板打不开 | 云防火墙未放行面板端口 |
